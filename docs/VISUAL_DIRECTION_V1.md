# Capiday Visual Direction v1 Review（2026-11-18 Founder 已确认 → V10.85 实施 Phase 1）

> 2026-11-18。基于 Founder 提供的参考图（首页 / 月令集章 / 集章样式 / 纸张 / 封面 / 配色 / 字体）和当前代码（V10.84）。
> **这一轮只是设计系统方案，没有改 App 界面。** 确认后按 Phase 1 → 2 → 3 分批实施，每批单独发布、单独真机看。
> 方向一句话：**Modern Editorial Journal × Chinese Stationery Sensibility × Living Media** ——约 70% 现代编辑设计 + 30% 中国文具 / 册页气质。

## 1. Captain 新定位（总结）

**Captain = Capiday 的守册猫 / Little Keeper。**
中文：「Captain 陪你把生活慢慢收进手帐里。」
English: “Captain is Capiday’s little keeper, helping you collect your days gently.”

| 职责 | 现在已有（查过代码） | 调整 |
|---|---|---|
| ① 帮用户盖章 | V10.84 首次盖章（数据事件 → 小胶囊 + 朱印 + light 触感），没有 Captain | Captain 已开启时，**偶尔**（不是每次）坐在章旁边；Phase 3 才做「伸爪按章」动画（需要新美术） |
| ② 帮用户开始记录 | 首页刊头问句、每日一问、Captain 面板里的「写一句 / 选照片」按钮（`cp-go`） | 把这些引导统一成 Captain 的一句话 + 一个按钮，**不进入聊天** |
| ③ 轻提醒 | 每日提醒（本机通知，可关）；首页「今天还没记」状态 | 文案统一为温柔语气，**不出现**「还没完成 / 断了 / 连续」；不新增通知 |
| ④ 回看反馈 | 这一周卡片、那年今日、集章卡 | Captain 在这些卡片上**偶尔**说一句（本地文案，不需要 AI） |

**能力分层**

- **Level 1 · 非 AI（先做完）**：首页陪伴、盖章旁的出现、记录引导、温柔提醒、周回看一句话、功能引导、空状态陪伴。没有大模型也成立。
- **Level 2 · 轻 AI（以后）**：推荐标题 / 照片配文 / 一周一句总结 / 根据照片给一个记录问题 / 整理文字。定位是 Creative Assistant，结果都要用户点「用这句」才写进页面。
- **Level 3 · 开放聊天（降级为可选）**：现有 Captain's Corner 的「聊天」页保留，但：首页不再把聊天作为 Captain 的主要入口（现在是「找 Captain」标签）；不做长期人格记忆、情绪陪聊、高频推理。Mac 上的本地 Qwen 实验继续只作开发工具。

**Captain 不做**：独立聊天 App、心理咨询角色、高频消息机器人、任务管理、强 gamification 吉祥物、Duolingo 式催促。
人格关键词：安静 · 温柔 · 有一点可爱 · 不抢注意力 · 像守着一本册子的猫。不穿汉服 / 官帽 / 古装；还是一只现代、自然的小猫（现有柠檬帽、毛线球等轻装扮保留）。

**需要改的现有文案（Phase 1）**：首页 Captain 标签「找 Captain」/ “Ask Captain”（点开是聊天面板）→「Captain 在帮你看着这本册子」/ “Captain is keeping your book.”；邀请卡「想要一个陪你记录的小伙伴吗？」保留，副标题改为「它会帮你盖章、提醒你回来看看。聊天是可选的。」

## 2. 当前 UI 保留什么（不用改）

- **App Shell 全部保留现代样式**：底部 Tab、搜索、设置、编辑器工具条、相机 / 照片 / 分享、系统对话框、视频和录音控制。它们已经是 iOS 原生风格的圆角 + 无衬线（`--ui-sans` 系统字体），美国用户零学习成本。
- **首页结构**（V10.84 已定）：今天 → 小按钮 → 集章卡 → 这一周 → Captain → 我的手帐 → 页脚。不加回「今天的小计划」。
- **集章数据和规则**（`recordedDays`、空章、首次盖章事件）：只改外观，不改数据。
- **大日期刊头**（18 · 十一月 · 2026 · 星期三）：已经是最强的品牌资产，参考图也沿用，只调字体和层级。
- **照片为主角的页面排版**（杂志 / 拼贴 / 双照片排版）和手绘板。
- **用户自定义封面**（22 个封面模板 + 自己的照片）：核心能力不动，只新增 / 调整默认模板。

## 4. 新 color tokens

原则：沿用现有暖色；**朱砂只用于印章、日期小字和少量集章状态**；任何文字都要在宣纸白上达到 WCAG AA（4.5:1）。下面的对比度是实际计算值。

| 新 token | 中文名 | 值 | 用途 | 对比度（在宣纸白 #F8F5EC 上） |
|---|---|---|---|---|
| `paper` | 宣纸白 | **#F8F5EC**（现 cream #F8F5EF，几乎不变） | 主背景 | — |
| `paperCard` | 素笺 | #FFFDFA（现 paper，不变） | 卡片、页面 | — |
| `ink` | 墨褐 | **#3A3228**（现 #2F2A26，略暖） | 主文字，不用纯黑 | 11.56 ✅ |
| `inkSoft` | 淡墨 | **#756D63**（替换现 muted #8D857B） | 次要文字、说明 | 4.67 ✅（现 muted 3.34 ❌，这是现有问题） |
| `bamboo` | 竹青 | #6B7F62 | 大面积填充、图标、这一周卡片背景 | 3.98（**不用于正文小字**） |
| `bambooDeep` | 深竹青 | #55684A（现 sageDeep，不变） | 主按钮、链接文字 | 5.56 ✅；白字在上面 5.97 ✅ |
| `cinnabar` | 朱砂 | #C2544A | **只用于印章的填充 / 描边、小印** | 4.13（**不用于小字**） |
| `cinnabarInk` | 朱砂字 | #A9483A（现 `--c-a9483a`） | 「已集 5 枚」等少量朱色文字 | 5.24 ✅ |
| `moon` | 月白 | #E4EDF1 | 可选辅助底色（月白纸、引用块） | 墨褐在上面 10.61 ✅ |
| `sage` / `blush` / `butter` / `kraft` / `lemon` / `blue` | — | 保留现值 | 现有主题、贴纸、标签 | — |

- 全部写进 `Packages/…/Resources/design-tokens.json`，用 `tools/sync_tokens.py` 生成 CSS（不手写第二套颜色）。旧 token 名保留为别名，避免一次性改几百处 CSS。
- 用量上限（写进 DESIGN_SYSTEM）：一屏里朱砂面积 ≤ 约 3%；一张卡片里朱色元素 ≤ 3 处。
- 深色主题：朱砂在深色背景上提亮到 #D9776B，竹青提亮到 #8FA584（Phase 1 一起出，需要截图核对）。

## 5. Typography hierarchy

不大面积使用毛笔字 / 书法字。中文标题用**宋体气质**，正文保持系统字体的可读性；英文用温和的 Serif + 干净的 Sans。

| 层级 | 中文 | English | 字号 / 字重（iPhone） | 用在 |
|---|---|---|---|---|
| Display 日期数字 | 「18」Serif 数字 | 18 | 64–72 / 400 | 首页刊头、页面日期 |
| H1 刊头 / 月份 | 宋体：十一月、今天已经记下来了 | Serif：November | 22–26 / 600–700 | 首页问句、集章卡月份、封面标题 |
| H2 区块标题 | 宋体：今天的故事、我的手帐 | Serif：Today’s Story, My Books | 20–22 / 600 | 首页各区 |
| Kicker 小标题 | 系统字 12，字距 0.12em：这个月 · 月令集章 | Sans 11 大写，字距 0.14em：THIS MONTH | 11–12 / 500 | 卡片顶部 |
| Body 正文 | 系统字（苹方）15–16 / 行高 1.6 | System 15–16 / 1.5 | — | 说明、页面正文默认 |
| Caption 说明 | 系统字 12–13，淡墨 | System 12–13 | — | 日期、计数、照片说明 |
| UI 控件 | 系统字 | System | 13–17 | 按钮、工具条、Tab（**不改**） |

- 中文宋体字体栈：`"Songti SC", "STSong", "LD-zh-xiaowei", "Noto Serif SC", serif`（iPhone 自带 Songti SC，App 包不变大）。英文 Serif：`"LD-elegant"（Cormorant Garamond）` 用于大标题，`"LD-vintage-serif"（Libre Baskerville）` 用于小号 Serif（Cormorant 小字号太细）。
- `LD-chinese`（马善政毛笔字）**从所有界面字体栈里移除**，只留在用户可选的页面字体里。
- 用户自己的标题 / 正文字体选择不受影响。

## 6. Stamp visual system

三种章 + 两种空位，全部同一个圆形尺寸体系（首页 20 px，集章卡 40 px，盖章胶囊 44 px）：

| 类型 | 何时 | 外观（升级后） |
|---|---|---|
| **Photo Stamp 照片章** | 那天有自己的照片（照片墙规则） | 照片 **降饱和 + 75% 不透明**，1.5 px 朱砂细圈；不再是鲜艳的小照片 |
| **Small Seal 字章** | 没有照片：那天第一个字 | **白底 + 朱砂描边 + 朱砂字**（取代现在的朱砂实心圆），印章感、更轻；极个别（今天、首次盖章那一下）才用实心 |
| **Date Stamp 日期章** | 页面删除后（空章） | 朱砂细虚线圈 + 日期数字（淡墨），和「从没记过」区分 |
| 从没记过 | — | 极淡的点线圈（`line` 色），不是叉、不是灰块 |
| 今天还没记 | — | 竹青虚线圈 |

- 参考图里的「晴 / 雨」天气章：**不自动读天气**（需要定位权限，和「不收集」的隐私承诺冲突）。Phase 3 可以加「今天一个字」：用户自己选（晴 / 雨 / 旅 / 家…），只是装饰，可不选。
- 集章卡标题：中文「月令集章」，英文 **“This month”**（首页）/ **“November”**（集章卡页标题，副标题 “6 kept so far”）。不直译成 “Monthly Seal Collection”。（问题 Q2）
- 月令 / 节气：Phase 3，只在集章卡角落一行小字（例：「小雪 · 11月22日」/ 英文不显示或显示 “First snow”），可在设置里关掉。海外用户不需要懂节气也能用。

## 7. My Books cover direction

**Modern editorial notebook cover + subtle Eastern details**：布纹 / 纸感底色、现代 Serif 标题、少量植物线稿、底部一枚很小的朱印。**不用**线装书、竖排中文标签、古籍封面、大面积纹样。

三个新的默认封面模板（加进 `library.json coverTemplates`，原有 22 个保留）：

| 模板 | 底色 | 标题（示例） | 细节 |
|---|---|---|---|
| `capiday-travel` | 竹青布纹 | **Travel Notes** / Buenos Aires · 2026 | 右下一枝白花线稿；底部 8 px 小朱印 |
| `capiday-captain` | 奶油白 | **Captain** / Little days at home | 简单 Captain 线稿（现有素材描线）；淡纸纹；小朱印 |
| `capiday-food` | 宣纸白 | **Things We Ate** / 2026 | 现代 Serif；一张食物照片或植物插画；**无中文元素** |

- 用户输入的书名原样显示，不翻译；中文书名用宋体，英文用 Serif（沿用 V10.78 的「封面跟随字体」）。
- 参考图里的书封中文小竖标签（「我的猫」竖排）不采用。

## 8. Journal page direction

编辑器保持现代；**生成 / 阅读出来的页面**有现代册页感：

```
11月18日 · 星期三                         (晴)  ← 很小的字章，只在用户选了「今天一个字」时出现
──────────────────────────────
[ 照片（主角，杂志 / 相册排版，不加传统框） ]

  留白

  天很好，走路回家。                        ← Serif 标题或正文，保持可读

  ◉ 声笺 · 00:18  ▁▂▅▃▂▁▃▅▂               ← 录音（第 9 节）
  [ 视频封面  ▶ 00:12 ]                     ← 视频（第 9 节）

                          CAPIDAY · NO. 18  ← 已有页脚
```

- 照片：沿用现有排版（杂志、相册、拼贴、双照片）。
- 文字：靠留白、Serif、小标题和纸纹取得册页感；不把文字变成书法。
- 手绘：天然兼容，保持现状（「随手画在笺纸上的一笔」）。
- **Signature Papers（Phase 2）**：宣纸白 Warm Paper · 素笺 Plain Letter · 淡格 Soft Grid · 月白 Moonlight · 草叶纸 Leaf Paper。只做细微纸纹 / 纤维感，不用龙凤、祥云、大红纹样、古典边框、宫廷图案。原有 9 种纸保留。

## 9. Audio / Video 如何融入

- **Voice note / 声笺**（新的默认外观，现有三种外观保留可选）：阅读状态是一行——朱砂小圆点 ◉ + 时长 + 极细波形 + 一行小字。
  - 中文：「声笺 · 00:18 · 听听当时的声音」
  - English: “Voice note · 0:18 · Recorded that day” / 按钮 “Listen”
  - 点一下才展开完整播放（进度、倍速、标题编辑），离开页面自动停（现有逻辑）。
- **Video**：页面里永远是视频封面 + 「▶ 00:12」；点开进入全屏沉浸播放（系统控制条只在播放时出现）。要改的一处：日详情里不在页面上的视频（`day-view.mjs` → `canvas.mjs` `mediaCardHTML`）现在常驻 `<video controls>`，改为封面 + ▶。
- 录音、视频的按钮和进度条属于 App Shell，保持现代 iOS 样式；只有「页面上静止的样子」有纸感。

## 10. Captain 在各页面出现的位置

| 页面 | 位置 | 频率 / 规则 |
|---|---|---|
| 首页 · 还没记 | 照片卡右上方（现有位置），一句引导：「今天有什么值得留下来的？」 | 一直在（已开启 Captain 时）；不说话时只是坐着 |
| 首页 · 已记 | 今天这一页上方，安静的样子；可点开小面板 | 不主动说话 |
| 首次盖章 | 小胶囊旁边 Captain 小头像（现有 peek 图） | **偶尔**：每周最多 2 次，或这个月第一枚章；其余只有章（保持惊喜） |
| 集章卡 | 右下角一摞册子旁的 Captain（参考图） + 一句回看：「这个月已经留下好多小日子啦。」 | 有 ≥ 5 枚时才说 |
| 这一周 | 卡片角落 Captain 小图；周页底部一句：「这一周好像发生了不少事。」 | 每周一次 |
| 空状态（没有书、没有照片） | Captain + 一句引导 + 一个按钮 | 只在空状态 |
| 编辑器 / 阅读器 / 设置 | **不出现**（不打扰记录和阅读） | — |
| 聊天 | 只在 Captain 小面板的「聊天」页，入口降级为次要 | 可选 |

- 没开启 Captain 的用户：以上位置都不出现，章和文案照常。
- 伸爪按章动画、坐在册子旁的插画：需要新美术（参考图的 Captain + 书堆 + 小印），Phase 3。

## 13. 实施范围

### Phase 1 · 低风险、可快速上线（约 1 个版本）
1. 颜色 token：新增第 4 节的语义 token（含 muted → 淡墨 #756D63 的对比度修正）、深色主题对应值，`sync_tokens.py` 生成。
2. 字体层级：中文标题统一宋体栈，移除界面里的毛笔字后备；英文 Serif / Sans 层级（第 5 节）。
3. 集章：字章改描边印章、照片章降饱和、空位更轻（只改 CSS / 章面渲染，不改数据）。
4. 这一周卡片配色（竹青或宣纸，Q3）；首页留白微调。
5. Captain：文案和入口降级（聊天不再是首页主入口）、首次盖章旁偶尔出现（现有素材）。
