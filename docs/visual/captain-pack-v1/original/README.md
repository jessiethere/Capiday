# Captain Illustrated Asset Pack v1

Capiday 的 Captain 新增素材。每张都是独立 RGBA PNG，可直接放到自己的卡片或纸纹背景上。

| 目录 | 素材 | 导出宽度 |
| --- | --- | --- |
| poses | 醒着趴卧、看手帐、卡片边探头 | 768 px |
| expressions | 平静、开心、好奇、困 | 600 px |
| portraits | 头像、半身小图 | 600 px |
| accessories | 独立柠檬帽、毛线球 | 512 px |
| interactions | 打招呼、温柔提醒、每周回看 | 768 px |
| playroom | 观察、伸爪、推球、收爪 | 768 px |

- 「闲着」沿用已批准的坐姿、睡姿。「盖章时刻」沿用已批准的准备盖章、按下印章。
- 探头图的卡片边缘放在两爪之间的胸毛底线附近，让两只爪子搭到卡片前面。
- Playroom 四帧共用 768 × 512 px 画布。按文件名顺序切换，各帧保留同一原点。点按后可以依次显示 160、130、130、360 ms，然后停在第 4 帧。
- 场景图从水彩原稿裁出并统一导出到 768 px 宽。以 3× 渲染时，场景和动画可显示到 256 pt 宽，头像和表情可显示到 200 pt 宽。
