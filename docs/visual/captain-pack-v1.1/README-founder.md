# Captain Playroom Asset Addendum v1.1

配合 Captain Illustrated Asset Pack v1 使用。每帧都是 768 × 512 px 的透明 PNG，按文件名顺序播放，所有帧使用同一画布与原点。接入时固定容器尺寸和对齐方式，使用 contain，避免逐帧裁切、缩放或重设对齐。

| 路径 | 动作 | 播放节奏建议 |
| --- | --- | --- |
| playroom/yarn-lemon-hat/ | 戴柠檬帽，观察 → 伸爪 → 推球 → 收爪 | 160 / 130 / 130 / 360 ms |
| playroom/hug/ | 看抱枕 → 靠近 → 双爪抱住 → 贴着抱枕安静下来 | 180 / 150 / 220 / 420 ms |

点一下播放一轮并停在末帧。重复点击可重新播放。柠檬帽已绘制在对应帧里，未戴帽的毛线球动作使用 v1 的 playroom/01–04 PNG。

每周回看的入口使用 v1 的 poses/reading-journal.png，回看内容页可用 v1 的 interactions/weekly-recap.png。引导卡与设置的小圆头像可用 v1 的 expressions/happy.png。
